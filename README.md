# ArcheCode — парсер-анализатор ваших проектов
 Пространство для управления проектами. Вы сможете добавить открытый репозиторий с гита, после чего он спарсится и превращатится в архитектурный граф, где каждый узел графа это файл или папка по которым можно запросить описание от ИИ. Если это файл, то можно выделить строчки и запросить информацию о них. Можно оставить комментарии к узлам и строкам файла, и запрашивать тестирование на выбранный узел. Можно добавить корпоративный чат, канбан, всякие приколы взаимодействия, миты, звонки и всё такое

## Стек технологий
- Next.js
- Spring
